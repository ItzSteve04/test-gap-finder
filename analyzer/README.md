analyzer/
│
├── code_analysis/
│   Inspect the source code of the repository.
│
├── coverage_analysis/
│   Examine existing test coverage and identify poorly covered areas.
│
├── gap_detection/
│   Combine information from the source code, tests and coverage
│   to identify important missing test cases.
│
├── test_generation/
│   Handle creation of new targeted tests for identified gaps.
│   This is where IBM Bob will play an important role.
│
└── runner/
    Execute tests and collect their results.
