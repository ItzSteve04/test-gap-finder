## Submission Checklist

Before final submission, verify that:

- Every team member has included their screenshots
- The screenshots are readable
- The screenshots show the relevant Bob task session summary
- The image files have been committed to Git
- The files have been pushed to the public repository
- The images can be opened from GitHub while logged out

## Security

Do not store any secrets in this directory.

Do not include:

- API keys
- Passwords
- Access tokens
- Gemini credentials
- IBM Cloud credentials
- Private environment variables

Screenshots should also be checked to ensure they do not accidentally expose credentials.
